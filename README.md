## 🚀 Visão Geral

**Data Report Engine** é um pipeline automatizado que:
1. Lê planilhas de vendas e outros datasets.
2. Processa, limpa e padroniza dados usando **Pandas**.
3. Gera análises, métricas, agregações e insights.
4. Produz automaticamente um relatório consolidado (PDF, CSV ou HTML).

Este projeto foi desenvolvido para demonstrar habilidades sólidas em:
- Manipulação de dados com Pandas  
- Automação de análises  
- Engenharia de pipelines simples  
- Criação de relatórios reutilizáveis  
- Estruturação profissional de projetos Python para portfólio

---

## 🧠 Problema

Empresas recebem arquivos de vendas (Excel/CSV) frequentemente:
- Despadronizados  
- Cheios de inconsistências  
- Exigindo retrabalho repetitivo para gerar relatórios semanais/mensais  

O projeto resolve isso criando um **pipeline reprodutível e automatizado**.
